## 워크플로우 

1. 화면의 영역은 로고/메뉴바/메인화면/팝업화면으로 구성된다. 
2. 초기 접속 시 감상평 조회 메뉴가 Default로 오픈된다. 
3. 메뉴바는 감상평, 영화정보로 구성된다. 각 메뉴 버튼을 클릭하면 해
당 메뉴로 이동된다. 
4. 감상평 조회 메뉴에서 감상평 등록 버튼을 클릭하면 감상평 작성 팝업
이 메인화면 위에 출력된다. 
5. 감상평 작성 후 저장하면 지정경로에 Text 파일이 생성된다. 
6. 감상평 작성이 완료되면 팝업이 사라지고, 감상평 조회 화면이 한번 
더 조회된다. 
7. 조회 된 리스트 중 대상을 선택하여 클릭하면 해당 감상에 대한 정보
를 불러와 감상평 팝업에 출력된다. 
8. 감상평 팝업의 수정 버튼을 클릭하면 감상평 작성 모드로 변경되고, 
저장 시 수정내용이 반영된다.

9. 감상평 조회 결과의 각 row의 수정 버튼을 누르면 감상평 팝업가 수정
모드로 활성화되고, 삭제 버튼 클릭 시 삭제 확인 후 해당 row를 삭제한
다.
10. 영화정보조회 화면은 현재 날짜 기준으로 개봉 중인 영화를 표시한
다. 
11. 영화정보조회화면에서 개봉 중인 영화 리스트 중 하나의 셀을 클릭하
면 영화에 대한 정보가 출력되는 팝업이 출력된다. 
12. 로그인하지 않은 사용자가 감상평 메뉴에 접근하면 로그인/회원가입 링크가 있는 
안내 화면이 표시된다. 영화정보 메뉴는 로그인 여부와 관계없이 접근할 수 있다. 
13. 헤더의 로그아웃 버튼을 클릭하면 로그아웃 처리 후 초기 화면(감상평 조회, 
비로그인 상태)으로 이동한다.
