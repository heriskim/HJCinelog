## 로그인/회원가입 기능 Spec

1. 로그인 방식은 이메일/비밀번호 방식만 지원한다 (Supabase Auth).
2. 회원가입 화면에서 이메일, 비밀번호(6자 이상)를 입력하여 가입한다.
3. 가입한 이메일은 중복될 수 없다.
4. 로그인 화면에서 이메일, 비밀번호를 입력하여 로그인한다.
5. 로그인에 성공하면 감상평 조회 화면으로 이동한다.
6. 로그인 상태는 세션(쿠키)으로 유지되며, 브라우저를 새로고침해도 로그인 상태가 유지된다.
7. 로그아웃 버튼을 클릭하면 세션이 종료되고 비로그인 상태가 된다.
8. 로그인하지 않은 사용자는 감상평 작성/조회/수정/삭제를 할 수 없으며, 감상평 메뉴 진입 시 로그인 안내 화면이 표시된다.
9. 영화정보 조회 메뉴는 로그인 여부와 무관하게 접근할 수 있다.
10. 감상평은 작성한 사용자 본인만 조회/수정/삭제할 수 있다 (Row Level Security 적용).
