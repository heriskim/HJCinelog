##감상평 작성 기능 Spec

1. 감상평은 제목, 평점, 감상평, 한줄평,작성일자으로 이루어짐. 
2. 제목은 최대 30자, 평점은 1~5의 숫자(0.5단위로 부여 가능함),
    감상평은 최대 2000자, 한줄평은 최대 100자
3. 각 감상평은 감상평ID로 구분한다(감상평 ID가 PK 역할 수행)
4. 감상평ID는 YYMMDD00001 형식으로 생성 날짜와 5자리 숫자로 구성된다.  
5. 감상평ID는 중복될 수 없으며 최초 생성 시 
   현재 날짜 YYYYMMDD + 현재 날짜의 마지막에 생성된 감상평의 ID + 1로 발번된다. 
6. 최초 생성되는 감상평ID의 숫자부분은 00001이다. 
7. 감상평 작성 화면에서 각각의 데이터를 입력한다. 
8. 저장 버튼을 클릭하면 JSON 형식으로 변환하여 지정된 저장 경로에 저장된다. 
9. 저장경로 : root/savedData/review
