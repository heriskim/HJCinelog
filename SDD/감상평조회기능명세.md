## 감상평 조회 기능 Spec

0. 감상평 조회는 로그인한 사용자만 가능하며, 본인이 작성한 감상평만 조회할 수 있다(로그인하지 않은 경우 로그인 안내 화면이 표시된다). 
1. 감상평을 Grid 형식을 보여준다. 
2. 각 Gird에는 제목, 평점, 작성일자를 표시한다. 
3. 감상평 조회화면에 접속하면 로그인한 사용자가 지금까지 작성한 감상평을 모두 표시한다. 
4. 20개씩 페이지로 구분하여 표시한다. 
5. 제목 / 작성일자로 원하는 조건의 감상평을 조회할 수 있다. 
6. Gird에서 감상평을 선택하여 클릭하면 Pop-Up으로 작성된 내용을 확인할 수 있다.
7. 6번의 Pop-up에는 클릭 시 감상평 수정 기능을 활성화하는 수정 버튼이 존재한다. 
8. Grid에 수정/삭제 버튼을 표시하는 칸이 존재한다. 
9. 수정 버튼을 누르면 선택한 row의 수정 Pop-up이 출력된다. 
10. 삭제 버튼을 누르면 선택한 row의 삭제확인 창이 표시되고, 삭제를 확인하면 해당 row가 삭제된다.
